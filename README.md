## Desarrollo local

El sitio utiliza HTML, CSS y JavaScript. Para servirlo localmente desde la raíz del repositorio, ejecuta `python -m http.server 8000` y abre `http://localhost:8000`.

El contenido traducido y las interacciones están en `tema.js`. La estructura está en `index.html`, los estilos en `styles.css` y el CV en `assets/`.
